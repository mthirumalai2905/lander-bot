# lander-bot

AI design editor POC. Natural language goes to structured component operations, then a deterministic engine updates the canvas.

## Run locally

```bash
npm install
npm run dev
```

Add your key in `.env.local` (see `.env.example`):

```
DEEPSEEK_API_KEY=
DEEPSEEK_BASE_URL=https://api.deepseek.com
```

Open http://localhost:5173/
